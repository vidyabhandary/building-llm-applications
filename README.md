# Building LLM Applications

Code associated to the book AI Applications with LangChain.

Some points

1. The Jupyter notebooks were run in Google Colab.
2. Used OpenRouter and not OpenAI API key
3. Tavily search instead of DuckDuckGoSearch (Faced some limit issues)
4. HuggingFaceEmbeddings with model_name="sentence-transformers/all-MiniLM-L6-v2" for embeddings
